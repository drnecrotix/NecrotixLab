# v1.3.101 - Fix CV download delivery

- Read managed CV PDFs directly from local uploads or R2 using their stored media key.
- Remove the public-host HTTP request for managed files that caused `fetch failed` on some deployments.
- Retain attachment headers and external media delivery.
- Remove the oversized Background/category sidebar and show all enabled categories together.
- Redesign Timeline with compact year labels, a single vertical rail and aligned responsive cards.
- Respect disabled resume settings and log storage errors server-side with a useful public error.

Validation: TypeScript, ESLint and unit tests, including route-level mocked local/R2 downloads without network access.
