# v1.3.75

- Page Access now covers content routes besides Homepage: Wiki, Blog, Gallery, Projects, Journey and Career Dossier, plus the existing Store control.
- Public, Admin only and Off apply to those route families, the public navigation and the sitemap.
- Lab, Tools, Services and other Addons routes stay outside Page Access.
- Types & Categories now includes Project categories.
- Admins can add, edit and remove project categories used by project forms and the public archive.
- Renaming a project category updates existing projects that use that label.
- Categories already assigned to projects are imported into the managed list automatically.
- Wiki Related pages and sources uses a compact list instead of cards.
