# v1.3.39

- Tools now includes dedicated Site Health and Security Center pages with categorized checks, quick links, impact explanations and guided resolution steps.
- Health and security warnings are retained in a deduplicated seven-day log that authorised admins can clear manually.
- The public-site probe now tries configured canonical origins before reporting a failure, and the Security Center scores browser, transport, authentication and privacy safeguards separately.
- Gallery rendering now falls back safely when WebGL is unavailable, protected Gallery media avoids unrelated content scans, browser/CDN caching is enabled, and images fade in only after decoding to prevent visible partial rendering.
