# v1.3.93

- Booking addon 1.2.0: upcoming/past/unconfirmed views, search and customer history.
- Private administrator notes and private projects with manual/automatic creation and status tracking.
- Optional email reminders with signed cron access, durable queue, atomic claims and bounded retries.
- Cancel/reschedule invalidates old reminders and preserves an existing project on UID changes.
- Responsive booking rows and subtle reduced-motion-aware service hover effects.
- Cal.diy Stripe setup link; payment verification and refunds remain external.

Deployment: run `npm run db:deploy`, configure CMS SMTP and independent `BOOKING_CRON_SECRET`, and schedule POST `/api/booking/reminders` every five minutes. Both workflows default to disabled. See Addons/Booking/README.md for acceptance checks and delivery guarantees.
