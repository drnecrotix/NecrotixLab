# v1.3.71

- Consolidate the complete Tools catalogue under one Addons package, with all tool settings in Admin / Addons.
- Move tool UI components and configuration into `Addons/Tools`; keep Next.js route entry points under `src/app` for build discovery.
- New seed installations start with Tools disabled. Existing installations retain their current setting.
- Add authenticated ZIP download and validated manual install/update, plus activate, deactivate and uninstall controls. A newer code package requires deploying the matching CMS build first.
- Add a GitHub-backed Addons catalogue that reads each folder manifest on `main` and displays available versions.
