# NecrotixLab 1.3.50

## Necrotix Workspace integration

- Connects accepted Service Requests to the independent Necrotix Workspace project delivery system.
- Signs every server-to-server handoff with HMAC-SHA256 and a short-lived timestamp.
- Transfers the accepted customer, scope, selected services, requirements and quote without exposing the shared secret to the browser.
- Stores the linked Workspace project ID, project key, private client URL, sync time and last integration error.
- Adds an admin action for creating the Workspace project only after quote acceptance.
- Adds the private Workspace link to the customer's existing signed request status page.
- Includes the database migration, deployment environment variables and signature regression coverage.

## Deployment

Run `prisma migrate deploy`, then configure `NECROTIX_WORKSPACE_URL` and the same 32+ character `NECROTIX_WORKSPACE_SECRET` in both deployments.
