# v1.3.50

- Accept sanitized SVG logos through media uploads and selectors.
- Refresh generated PWA icon URLs on settings saves; revalidate generated icon and splash responses.
- Preserve unrelated caches, protect the offline fallback from optional precache failures, bound cached entries, and tolerate storage exhaustion.
- Exclude dynamic PWA icons and manifests from the offline cache.

Implementation references: [Serwist](https://github.com/serwist/serwist), [Workbox](https://github.com/GoogleChrome/workbox), and [PWABuilder](https://github.com/pwa-builder/PWABuilder). Applied targeted improvements to the existing worker without migrating the build pipeline.

Installed home-screen icon refresh remains browser-controlled. SVG uploads support vector shapes and gradients; scripts, external resources, embedded HTML and stylesheets are removed.
