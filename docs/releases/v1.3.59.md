# v1.3.59

- Video Download now fetches pinned official yt-dlp release assets directly, verifies SHA-256, and retries with curl if Node's fetch cannot use the host proxy. The N0C updater records provisioning failures so the status message gives a concrete reason.
- Discord User ID lookup works without a bot token for ID-derived creation time and a profile link. It does not verify that the account exists; a bot token is still required for profile fields.
- EXIF Tool now edits common JPEG EXIF text fields and downloads a new JPEG. Existing clean-copy and local metadata inspection remain available. PNG, WebP, HEIC and TIFF writing is not supported by this editor.
