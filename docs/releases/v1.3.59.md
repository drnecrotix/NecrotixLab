# v1.3.59

- Video Download supports public X.com posts using the public embed feed and MP4 streaming. It no longer needs yt-dlp or permission to execute a binary on N0C.
- Discord User ID lookup works without a bot token for ID-derived creation time and a profile link. It does not verify that the account exists; a bot token is still required for profile fields.
- Discord Lookup shows available server or user avatars, banners and additional public profile fields. A bot token remains required for user profile fields.
- EXIF Tool edits JPEG description, document, camera, lens, ownership, dates and GPS coordinates or altitude and downloads a new JPEG. Existing clean-copy and local metadata inspection remain available. PNG, WebP, HEIC and TIFF writing is not supported by this editor.
