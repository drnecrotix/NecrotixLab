# v1.3.60

- Video Download now supports public X.com posts through the public embed feed and MP4 streaming. It no longer needs yt-dlp or permission to execute a binary on N0C.
- Discord Lookup displays available server and user avatars, banners and additional public profile fields. A bot token is still required to fetch user profile fields.
- EXIF Tool expands JPEG editing to document, software, camera owner and serial, lens details, digitized date and GPS altitude. PNG, WebP, HEIC and TIFF remain inspection-only.
