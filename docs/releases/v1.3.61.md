# v1.3.61

- Restore a compatibility entry point for `scripts/provision-video-backend.mjs`. Older updater processes call it after replacing the application files. The entry point exits successfully without installing yt-dlp, allowing those installations to finish updating to the X-only video backend.
- Offer the official X Downloader iframe widget as an explicit fallback when the built-in X lookup fails. The third-party widget loads only after the visitor clicks to open it.
