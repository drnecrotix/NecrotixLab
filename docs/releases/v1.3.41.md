# v1.3.41 - NecrotixLab admin workspace

- Add a flat, locally bundled Equal Earth map with real country boundaries, visit shading, keyboard selection and zoom.
- Retire A/B assignment, event collection and admin reporting; preserve the Audience & traffic route and historical database tables for a separate retention decision.
- Add responsive protected-media sizes without a second optimizer pass, image retry feedback and media failure diagnostics.
- Record redacted browser, render, resource, request and server failures in the seven-day operational log. Group repeated events into 15-minute windows and distinguish browser reports from verified application failures.
- Redesign Error log with search, source/severity filters, occurrence counts, first/last-seen context and investigation guidance.
- Add workspace breadcrumbs, health/security shortcuts, consistent admin surfaces/focus, density settings and configurable traffic refresh that pauses in hidden tabs.
- Rename project display metadata to NecrotixLab. The GitHub repository rename requires owner-level repository settings access and is not performed by this release.

## Validation and limits

- Run the included Prisma migration before serving the new logging endpoints.
- Diagnostic payloads exclude form contents, raw IPs, cookies, query strings and arbitrary exception messages. Browser reports are unverified and rate-limited per process.
- Error retention cleanup runs on log reads and incoming events; idle databases require a hosting scheduler for exact wall-clock deletion.
- Client-side capture cannot observe offline/blocked reports or every handled application error. A clear log is not a guarantee of error-free operation.
