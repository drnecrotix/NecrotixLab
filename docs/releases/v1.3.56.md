# v1.3.56

- Added Video Download for public Facebook, Instagram and X videos, powered by the open-source yt-dlp executable. The page checks backend availability and lists direct MP4 formats with audio. N0C requires a separately installed executable.
- Improved G/M-code writing with cursor-aware command insertion, formatting, comment shortcuts, find and replace, and clearer controls.
- Expanded the G-code simulation to explain each line and show Z, spindle, feed, coolant, tool, and work offset state. Unsupported machine-coordinate motion is not drawn as an ordinary XY move.
- Added security limits for video requests and downloads, with expiring signed links and a 250 MB stream cap.
