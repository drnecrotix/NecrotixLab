# v1.3.42 - Audience visitor list

- Enable the world map and visitor activity directly on Audience & traffic.
- Add a Visitors view with one row per browser session, device, operating system, location, IP and the latest viewed page. Keep Page history as a separate view.
- Fetch the latest 150 sessions for the selected period independently of the recent page-event limit, so a busy visitor cannot crowd everyone else out.
- Show LIVE only on the active session's current page within the five-minute heartbeat window.
- Open expanded provider, ASN, organisation, network domain, device, last-seen and page-history details by clicking an IP or anonymous visitor ID.
- Make visitor details keyboard-accessible, trap focus, support Escape and cancel a pending request when closed.
- Keep IP/network retention at 24 hours and page activity at 30 days. Location remains approximate and device classes do not identify exact hardware.
- Remove obsolete A/B cookie descriptions now that experiment collection has been retired.
