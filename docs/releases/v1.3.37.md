# v1.3.37

- Recent page activity now supports search and quick filters for live rows and rows with active IP context.
- IP details include IPv4/IPv6, ASN, ISP, organisation and network domain when the short-lived lookup provides them.
- Raw IP and associated network context expire after 24 hours. Detailed page activity and traffic aggregates expire after 30 days.
- Retention cleanup is claimed at most once every six hours and runs on the next page-view request instead of relying on random sampling.
- The implementation follows the focused, privacy-first direction of Umami, Plausible and Ackee without copying third-party code.
- The main admin dashboard is simplified: retained activity now lives only under Experiments > Audience & traffic, while Locations shows the top four countries or cities.
- Clicking an active IP opens visitor, network and recent-page details. A live badge now belongs only to the visitor's newest matching page event.
- Authorised admins can export the selected visitor-activity period as a spreadsheet-safe CSV without extending data retention.
- Site health now runs live checks for the database, public homepage, migrations, media storage and updater. A compact expandable security panel verifies response headers, authentication-secret strength, HTTPS and login throttling.
- Operational monitoring and security checks take product cues from Uptime Kuma, Gatus and Helmet without copying their code.
