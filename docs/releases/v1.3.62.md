# v1.3.62

- Offer the official X Downloader iframe widget as an explicit fallback when the built-in X lookup fails. The third-party widget loads only after the visitor clicks to open it; the link is then sent to x-downloader.com.
- Stop reporting aborted page navigation fetches as browser `NetworkError` incidents in Site Health. Existing page-only records are hidden from the log; API request failures and HTTP status errors remain visible.
