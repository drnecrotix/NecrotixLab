# v1.3.40

- Fixes public Gallery images that failed with HTTP 400 from `/_next/image` because protected media URLs include `?scope=gallery`.
- Allows `/api/protected-media/**` in Next Image `localPatterns` so query-string media is no longer rejected as `"url" parameter is not allowed`.
- Renders protected Gallery thumbnails and zoom-viewer images without a second optimizer pass, which already returns watermarked WebP from the media API.
- Adds a unit check for the protected-media optimizer bypass.

## Compatibility

- No Prisma migration.
- Existing Gallery watermark and media protection settings stay unchanged.
