# v1.3.46 - Homepage balance and CMS controls

- Reorders the homepage editorial sequence to Ideas, Journal, Engineering / CNC Lab, Selected work and Kreatrics Cloud.
- Aligns the Ideas capability grid and renames its first two cards to Community Hub and Discord Server.
- Removes the colored outer glow from the CNC and Cloud visualizations.
- Adds tabbed Homepage administration for Hero, Ideas, Journal, Engineering, Case studies and Cloud content.
- Adds a searchable shared icon library with 1,384 supported Lucide icons for Service Tools and future CMS modules.
- Adds focused PDF and document utility modules to the CMS-managed Tools catalogue.
- Adds an active Document Inspector & Privacy Cleaner with file-signature checks, metadata reporting, PDF risk markers, SHA-256 and local sanitized-copy export.
- Adds working, privacy-first Binary Converter, Base64 codec, File Hash and Hex Viewer tools that process data locally in the browser.
- Versions the Service Tools configuration so existing CMS installations receive the new modules once without preventing later removal or customization.
