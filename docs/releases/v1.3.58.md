# v1.3.58

- Fixed Video Download installation through the N0C updater, which intentionally skips npm lifecycle scripts. The updater now provisions the extractor explicitly and tries the standalone Linux executable if Python is unavailable.
- Added a specific Video Download backend status message to help diagnose deployment restrictions.
- Added "Check my IP" to WHOIS / IP Lookup. It detects the visitor IP from the proxy headers and runs the existing IP registry lookup.
- Added Discord Lookup for public invite details and server widgets, with optional bot-authorized user ID lookup. Arbitrary user and server-name search is not exposed by the public API.
- Added a browser-only EXIF Tool for photo metadata inspection, JSON export and clean copies of JPEG, PNG and WebP images.

Discord server lookup by ID requires the server's public widget. User ID lookup requires `DISCORD_BOT_TOKEN`; invite lookup works without credentials.
