# v1.3.74

- Available on Addons is only the install catalogue from GitHub (plus bundled Tools when the catalogue is offline).
- Installed lists packages already on this CMS as compact rows: status, activate/deactivate, update and uninstall. Tool settings no longer render on that list.
- Each addon keeps its own settings page. Tools settings live at `/admin/addons/tools`.
- Check updates refreshes the GitHub catalogue, reports how many updates exist, and surfaces update actions on both Available and Installed.
