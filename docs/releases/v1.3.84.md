# v1.3.84

- Improve G-Code Editor controls with icons, explicit labels, stronger contrast, keyboard focus states and primary playback/export actions.
- Move playback and line scrubbing above the preview; group file actions, editing tools and view controls.
- Replace the separate .nc/.txt export buttons with one Export file action and a format selector. Ctrl+S follows the selected format.
- Show synchronized top XY and side XZ depth projections by default; allow YZ depth, single-view enlargement and shared zoom/fit.
- Carry actual Z coordinates and spindle state through linear and helical-arc samples. Keep Z-only motion in depth views without inventing XY paths.
- Add a configurable stock-top Z reference. Split moves at the surface and distinguish potential cutting, air feed, rapid travel, rapid below the surface, and feed with spindle stopped. Planned motion uses faded styling independently of its motion type.
- Surface classification is an estimate, not volumetric stock removal or collision detection. Stock boundaries and tool geometry are not inferred from G-code.

## UI comparison

- NCnetic NC Viewer (https://nc-viewer.ncnetic.com/) groups load/new/download/reset actions. Adopt explicit file actions and a single export control.
- NCPlayer (https://ncplayer.trasa3.com/) provides plane views, fit-to-view, path/rapid colors and material configuration. Adopt synchronized XY/Z inspection, a compact view switch and a named motion legend.
- CAMotics (https://camotics.org/manual.html) distinguishes toolpath playback from workpiece/material simulation. Keep the surface reference visibly separate from true stock-removal claims.

## Validation

- Added unit coverage for Z-only projections, surface crossings, spindle state, helical Z interpolation and unknown first XY positioning.
- Updated browser regression coverage for dual projections and both export formats; full database-backed browser suite runs in CI.
- Manually checked desktop and a 360 px embedded viewport using temporary isolated preview scaffolding. Removed all preview routes/configuration before committing.
