# v1.3.34

- Installed app shows an **update notice** when a new release is on the server, not only when a waiting service worker appears.
- **Update** reloads into the latest version. If a service worker is registered, it is activated first (`skipWaiting` + `controllerchange`) so cached pages actually change.
- The notice checks on launch, when the app is focused, and every few minutes. Later dismisses it until the next session.
- `/pwa-sw.js` is no-cache so update checks hit the network. `APP_VERSION` in the worker matches `package.json`.
