# v1.3.48 - Local-first web utility suite

- Adds active grouped web utilities for text, images, calculators, units, URL/HTML encoding, JSON, URL/UTM, UUIDs, passwords, colors and subtitles.
- Consolidates repetitive single-purpose conversions into focused local-first workspaces inspired by WebTools, IT-Tools, CyberChef, DevToys and OmniTools.
- Keeps all text and image operations private inside the browser and registers every module in the editable Service Tools catalogue.
