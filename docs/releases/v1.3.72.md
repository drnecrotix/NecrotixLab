# v1.3.72

- Addons opens with an available package catalogue from the configured GitHub repository, plus Installed and Upload ZIP views, version/status labels and search.
- Install a compatible Tools release from GitHub or upload a ZIP. Custom packages are validated, retained privately, downloadable and removable, but remain staged until a reviewed CMS build supports their code.
- Keep uploaded archives in `storage/addons` through the CMS updater. No uploaded scripts execute in the running application.
- Refresh `/tools` with category filters, search and clearer active/planned states. Simplify individual tool settings and prevent activation of unimplemented routes. Disabled `/tools/*` routes and WHOIS endpoints now return 404.
