# v1.3.36

- Gallery images now import EXIF, IPTC and XMP metadata into empty Work details fields when selected or uploaded from Media Library.
- Metadata remains editable, can be re-read on demand, and never overwrites existing manual values. Raw GPS coordinates are detected but are not inserted automatically.
- The public Grid view uses a responsive masonry layout and preserves stored image proportions.
- Photography details now include image resolution. Obsolete Gallery settings that no longer controlled visible UI were removed.
